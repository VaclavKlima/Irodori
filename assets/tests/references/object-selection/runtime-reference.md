# Production runtime sampling references

`runtime-sampling.json` is generated by `scripts/research/object-selection/generate-runtime-reference.py` in the pinned `requirements-export.txt` environment. It contains sampled 1024-square RGB values from upstream PyTorch/torchvision antialiased bilinear resizing, and complete 37 × 19 binary coverage from PyTorch bilinear low-resolution logit reconstruction. The deterministic RGBA and logit generators are recorded alongside the numeric samples. The generator SHA-256 and package versions are recorded in the JSON. These synthetic vectors are numeric references, not photographs or annotated selection quality.

Regenerate explicitly with:

```sh
python scripts/research/object-selection/generate-runtime-reference.py --output assets/tests/references/object-selection/runtime-sampling.json
```

`runtime-cpu-only.onnx` is the generated StringNormalizer refusal graph from `scripts/research/object-selection/make-probe-model.py`: one string input `mask`, one uppercase output `MASK`, ONNX opset 17. Its SHA-256 is `8d29351450bddc8538ae7f64aee46f7bee6952457fc99d92ddd140b82d004223`. It deliberately has no WebGPU kernel. A GPU session that silently assigns it to CPU must fail the production policy test. It contains no trained model or external data.

Both generators and generated synthetic vectors are original Irodori test material under the repository's Apache-2.0 license. No model inference is needed to regenerate sampling references. Production installation and inference never invoke Python.
